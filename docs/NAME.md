# Project name: Meshvianex

The project is named **Meshvianex**.

The coined name combines **Mesh** (interconnected network paths), **Via** (routes and traversal), and **Nex** (connections, inspired by *nexus*). It reflects the modular Realm/Graph topology, flexible routing, and failover behavior of the networking runtime.

The product name is written **Meshvianex** in user-facing text and `meshvianex` in module paths, package identifiers, executable names, configuration paths, and environment variable stems (uppercase in the latter).

Name availability, domain availability, search-engine spelling treatment, and trademark clearance are separate checks and are not guaranteed by this repository.
